В ходе эксперимента алгоритм «Дерево решений» продемонстрировал значительно более высокую эффективность по сравнению с «Методом k-ближайших соседей» (kNN). Хотя потенциально производительность kNN можно улучшить путем тщательного подбора гиперпараметров и предобработки данных, в данной задаче «Дерево решений» оказалось предпочтительнее из-за его устойчивости к высокой размерности и лучшей интерпретируемости модели.
